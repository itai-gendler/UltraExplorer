# Shelf item

A file or folder kept on the optional drop shelf for a later transfer.

## Information kept

- **Path** — The linked original or the shelf-owned copy.
- **Added** — When the item was added.
- **Storage** — A path link, or an owned copy for temporary source material.
- **Arrangement** — Its retained place among the other shelf items.
